BIRTHDAY JHUNKI WEBSITE

1. Put your own photos in the images folder.
2. Rename them exactly:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   (PNG files can also be used, but then change .jpg in photos.js)
3. Open index.html in a browser.
4. Flow:
   index.html -> birthday.html -> countdown.html -> surprise.html
5. On the surprise page, tap the photo to change pictures.
6. The third photo triggers a balloon/confetti-style blast.

For GitHub Pages:
- Upload all files and the images folder to a repository.
- Enable Settings -> Pages -> Deploy from main branch.
- Open the generated Pages link.
